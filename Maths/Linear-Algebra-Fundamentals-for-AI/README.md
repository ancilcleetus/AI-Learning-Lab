# **Linear Algebra Fundamentals for AI**

Based On **Andrej Karpathy's Zero to Hero Course**: All lessons in this course are based on Andrej Karpathy's legendary "Neural Networks: Zero to Hero" YouTube series. His ability to explain complex AI concepts from first principles has inspired countless learners around the world.

## What you'll learn

Essential linear algebra and basic calculus concepts for understanding neural networks, taught entirely using Python and NumPy. Requires Python knowledge - complete [Python Fundamentals for AI](https://colab.research.google.com/github/ancilcleetus/AI-Learning-Lab/blob/main/Programming-Languages/Python/Python-Fundamentals-for-AI/Python_Fundamentals_for_AI.ipynb) course first or should already know Python basics.
